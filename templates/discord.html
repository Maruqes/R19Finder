Setup
  1. Create an application in the Discord Developer Portal. Under Bot, generate a token and paste it above.
  2. Under Installation → Guild Install, select bot and applications.commands. Grant View Channels, Send Messages, Embed Links and Read Message History. Use the install link to add the bot to your server.
  3. In Discord, enable Settings → Advanced → Developer Mode. Copy the text channel ID and your user ID into the fields above. Ensure the bot can access that channel.
  4. Save settings. Enable Discord notifications on the schedules you want. Allow notifications for this channel on your phone.

Keep Docker running. No public URL or Message Content intent is required.
